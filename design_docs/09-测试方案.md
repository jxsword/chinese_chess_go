## 2. 专项测试

### 2.1 规则引擎金标准对拍（跨语言）

- 金标准文件从 Electron 版 `tools/golden/` 复制到 `testdata/golden/`：`fen.json`（FEN 往返）、`moves.json`（AllLegalMoves 集合对拍 + 终局 status）、`notation.json`（中文记法逐字）、`engine.json`（findBestMoveEx 逐层 best/bestCp/topK；d5/d6 慢速对拍集由环境变量 `RUN_SLOW=1` 启用）。
- Go 测试：`internal/rules/golden_test.go` / `internal/engine/golden_test.go` 读取同一 JSON——**与 TS 版共用 Dart 提取的期望值**，跨语言逐位可比；同分着法间排序不参与对拍（Dart sort 不稳定）。
- **DR-006 口径**：全部对拍在**不传 HistoryFens** 前提下零改动成立；L3 裁决用例（SWING/QUIET/FACING 三类环）与 Electron 版 `test/rules/repetitionJudge.spec.ts` 期望逐条一致。

### 2.2 引擎/求解器

- L0 Zobrist：确定性快照 + 增量===重建 + 随机对局 120 步 + undo 复原（03 §4）。
- L1：缺省两次运行逐位一致；count=2/3 惩罚精确值（=静态评估−惩罚×(count−1)，无搜索噪声）；空表路径检测确定性冒烟；**性能门：开/关检测 nodeCount 差 ≤5%**（显式大超时，防 CI 负载假超时——Electron 版教训）。
- L2：pickAvoidanceMove 纯函数 5 场景（注入随机源）；**不传 HistoryFens 时 FindBestMove best === FindBestMoveEx best**；命中历史返回非重复着法；一步杀优先于回避。
- 性能门：难度 5 应答 ≤7.5s；求解器 6 验证 FEN 一致。

### 2.3 LLM 管线（Go mock SSE helper）

`internal/llm/mocksse_test.go`：可编程 httptest 服务器（可编程响应序列），覆盖 Electron 版 09 §2.3 失败模式表**全场景**：
正常增量+[DONE] / 围栏全角零宽 / 多坐标对+「着法:」标记 / 正文空退思维链 / 编造清单外着法→重试 / maxAttempts 耗尽→降级 / HTTP 4xx5xx→重试耗尽 / 空闲超时与总上限 / GLM thinking 参数断言（**请求体断言：恒发对应关闭参数**，DR-005）/ 候选模式编造非 Top-K / gate 否决→再问→二次通过/违抗。
**取消/断连场景中 mock 写已断开连接不得产生未处理错误**（Electron 版 CI 教训：mock 写 destroyed 流须守卫）。

### 2.4 goroutine/绑定集成

- 引擎协议 roundtrip、cancel 后立即 canceled 结算、迟到响应按 id 丢弃（**cancel 消息不得被测试拦截器误压**——Electron 版 engineWorker 教训）、同 Worker 串行 FIFO。
- storage：内存/临时库建表迁移、upsert 覆盖、死局清理、自动保存状态机全路径、fenHistory 四收口点（restore 跳脏）。
- 下载器：SSRF 白名单全表 + zip-slip 全表（沿 Electron 版 corpusDownloader.spec 逐条）；临时目录清理**先关 fd 再删**（Windows 句柄滞后教训）。
- 并发测试一律 `go test -race`。

### 2.5 E2E（Playwright，浏览器 mock 模式）

冒烟链路沿 Electron 版 09 §2.5：启动 → 主页 7 入口 → 双人走一着（棋盘坐标点击）→ 悔棋 → 新游戏 → 棋谱库打开。LLM/E2E 一律 mock（不依赖外部服务）。Wails 窗口本身不做自动化驱动（WebKitGTK 无 CDP）。

## 3. 测试目录与工具约定

```text
internal/**/*_test.go          # 与被测包同目录（Go 惯例）
internal/*/testdata/           # 包级测试资产（xqf 样例/求解 FEN）
testdata/golden/               # 跨语言金标准（只读，改动须 Electron 版依据并单独 commit）
frontend/src/**/*.spec.{ts,tsx} # 前端 vitest（jsdom）
frontend/e2e/                  # Playwright 冒烟（浏览器 mock 模式）
tools/golden-fetch.md          # 金标准来源与再生成说明（指向 Electron 版提取脚本）
```

- 快照测试仅用于提示词/PGN 导出/JSON 报告三类"协议面"；基准快照从 Electron 版既有快照复制起步，改动必须显式 review diff。
- **CI 平台性教训预防**（继承 Electron 版三项修复）：mock 写已断开连接须守卫；临时目录清理先关 fd 带退避重试；性能类用例显式大超时。
