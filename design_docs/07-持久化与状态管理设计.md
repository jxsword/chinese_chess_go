# 07 持久化与状态管理设计（Go 版）

> 继承：`/home/ssy/proj/chinese_chess_electron/design_docs/07-持久化与状态管理设计.md`。
> §1 数据库 Schema（表结构逐字段一致）与 §2 自动保存状态机、§5 棋谱联动为事实源，Go 版照搬；
> 本文记录 Go 版差异：SQLite 驱动（DR-002）、设置/凭据重裁（DR-004/005/011）、**§3 fenHistory 四收口点（DR-006 前置）**。

## 1. 数据库（modernc.org/sqlite；Schema 与 Electron 版逐字段一致）

- 文件：`<Documents>/chinese_chess_electron.sqlite`（懒打开；磁盘异常 → invoke 拒绝，前端按"本地存储不可用"降级，新局兜底——沿 Electron 版语义）。
- 表：`saved_games`（自动存档，每 mode 一条 upsert）+ `game_records`（棋谱库）+ 求解入库字段（solve_status）；**列名/类型/约束以 Electron 版 07 §1.1 与 `src/main/services/db.ts` 为唯一事实源**，Go 版 DAO（`internal/storage/db.go`）逐字段对照，含迁移 V1 与死局清理。
- 两套存档语义（自动保存 vs 手动棋谱）、存档 JSON Schema（`{fen, moves[]}`）不变；**restore 重放需同步重建 fenHistory（§3）**。
- DAO 测试：Electron 版 14 条 DAO 用例（内存库）翻译为 Go 表驱动测试。

## 2. 自动保存与恢复状态机（不变）

沿 Electron 版 §2：窗口 blur/minimize/close + before-quit → 自动保存（Wails 生命周期事件映射 `app:lifecycle`）；恢复时重放逐手重建（含跳脏记录语义——非法记录跳过且计数，测试沿 gameVm spec）。

## 3. GameVm 与 fenHistory（DR-006 前置；electron final §1 的四收口点）

`fenHistory []string`（完整局面 FEN，含轮走方；**长度恒 = moveHistory.length + 1**）是重复治理 L1/L2/L3 的数据基础，**M2 状态层首版即实现**：

| 收口点 | 行为 |
|---|---|
| 初始 / newGame / newGameFromFen | 重置为 `[当前局面 FEN]` |
| executeMove（落子后） | push 新局面 FEN |
| undoOnceInternal（悔棋） | pop |
| restore（重放） | 逐手采集（含跳脏记录语义；非法记录不 push） |

- 对外经 GameSnapshot 只读字段 `fenHistory` 暴露；四对局页调用 AI/LLM 时拷贝传入（`HistoryFens`，引擎侧单源转计数表——03 §6.2）。
- UI 裁决接线（`useRepetitionJudge` 移植）：effect 仅依赖 moveHistory.length，**仅历史增长时裁决**；历史缩短 → 重置 declined 标志与未决和棋框；`agreeDraw`/`resign(side)` 在 GameVm 首版即提供（GameResult 含 draw）。页面接线矩阵：M2 双人/人机页，M4 人机 LLM/LLM vs LLM 页。

## 4. 凭据存储（DR-004/011）

- 三槽位 `llm_config_red/black/assistant`，每槽位 JSON：`{baseUrl, apiKey, model, 使用预设名}`（**无 disableThinking 字段**——DR-005，关闭参数在请求构造层恒发）。
- 主存：OS keyring（`zalando/go-keyring`，service=`chinese-chess-ultra-go`，user=槽位名）。
- **回退（沿 electron-DR-011）**：keyring 不可用（无 secret service/凭据库锁定）→ 明文写 `<userData>/credentials.enc` 权限 0600，UI 如实回报"已用未加密本地文件存储"；读优先 keyring、回退文件；删除双向清理。
- 掩码语义（electron-DR-013）：回读给 UI 的 Key 一律 `****`+末4位；保存时掩码字符串不覆盖真实 Key（回写合并）。

## 5. 设置存储（非敏感）

JSON 文件 `<userData>/settings.json`（替代 electron-store）：键沿用 `llm_settings_*` 前缀（05 §8 表）；越界值 clamp 回默认（load 时）；结构化 getter/setter 经 `App.StoreGet/StoreSet`。

## 6. 前端状态管理（不变）

React 18 + Zustand **每局一实例工厂**（铁律 #6）+ 异步编排统一收口（requestId 取消/迟到丢弃/输入锁）——全部沿 Electron 版 §6.2/6.3，代码随 frontend/ 移植。
